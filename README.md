# Personal Expense and Budget Tracker

## Project Description 

This is a Javascript Personal expense and budget tracker. it stores income and expense transactions and performs calculations on the transaction data.

## Features

- Add a new transaction.
- Remove a transaction by its ID.
- Display all transactions.
- Display only income transactions.
- Display only expense transactions.
- Calculate total income.
- Calculate total expenses.
- Calculate current balance.
- Calculate expenses by category.
- Find the highest expense.
- Find the lowest expense.
- Calculate the average expense.
- Find transactions between two dates.
- Display transactions from the current month.
- Search transactions by description.
- Generate a monthly financial report.
- Display a warning when more than 80% of the budget is used.
- Display a warning when the monthly budget is exceeded.
- Display balance and budget information using a timer.


## How to Run the Project 

1. Open the budget.js project folder in VS Code.
2. Open the HTML file with Live Server.
3. Open the Browser Developer Tools.
4. Select the Console tab.
5. The results from the JavaScript Program will be displayed in the console.
